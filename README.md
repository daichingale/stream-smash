# Stream Smash

Windows向けのゲーム配信・録画ソフト。Switchのキャプチャー、ゲーム音とマイクのミックス、YouTube配信、スマブラのバースト集をひとつのアプリで扱う。

## 開発状況

手元の v0.20.6 は実行用パッケージ。Rust / Slint のソースを取り込んだ時点で、ビルド手順と対応デバイスを掲載する。v0.20.6 の実行ファイルでは合成映像60フレームのヘッドレスチェックが通った。実機キャプチャーとYouTube配信は別途検証する。

## 開発の優先順位

1. **配信と録画を安定させる。** キャプチャーボードの再接続、ゲーム音とマイクの同期、配信切断時のローカル録画継続、録画・配信それぞれのドロップフレーム表示を確認する。
2. **配信を始める前に状態を見通せるようにする。** 入力映像の解像度・fps、音声メーター、エンコーダー、配信先、録画先をプレビューと同じ画面で確認できるようにする。
3. **対戦から公開用クリップまでを短くする。** 撃墜・GAME SETの検出結果を一覧化し、誤検出を外してから縦動画へ書き出せるようにする。

## 比較のしかた

AVerMediaのキャプチャーボードと同じ映像・音声入力を使い、最初は1080p60で比較する。30分の録画・配信同時動作、入力の抜き差しと配信の切断、検出済みクリップからの書き出しを試す。フレーム落ち、音ズレ、CPU/GPU負荷、復帰時間、操作数を記録する。実測した結果を対応機種・設定とともに掲載する。
